Terminology

Regression AGWRC: the AGWRC calculated by imputing starting flow from manually selected flow event into AGWRC vs Flow Regression

Event AGWRC: the AGWRC from a known baseflow event identified by the workflow

Iterative AGWRC: the manually selected AGWRC that provides the “best fit” for the manually selected baseflow event

Starting flow: the observed flow at the first day of the manually selected baseflow event

MAE: Mean Absolute Error

RMSE: Root Mean Square Error

MAPE: Mean Absolute Percentage Error
